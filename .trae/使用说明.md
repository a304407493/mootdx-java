# code-extractor 技能使用说明

## 📖 简介

这个技能帮助您从 Java 后端项目中完整提取 API 接口代码，并提供 MD5 校验值以确保代码完整性。

## 🚀 快速开始

### 第一步：提取代码

当您需要 AI 复制某个 API 接口的代码时，使用以下提示词：

```markdown
请使用 code-extractor 技能提取以下接口的完整代码：

- **接口 URL**: http://localhost:8080/api/tdx-import/scan
- **项目目录**: mootdx-server

要求：
1. 按依赖顺序提取（DTO → Repository → Service → Controller）
2. 为每个代码块提供 MD5 校验值
3. 包含所有相关的私有方法和辅助类
```

### 第二步：验证代码完整性

AI 输出代码后，使用以下方法验证：

#### 方法一：PowerShell 快速验证

```powershell
# 将 AI 输出的代码粘贴到这里
$Code = @'
// 在这里粘贴完整代码
'@

# 计算 MD5
$Bytes = [System.Text.Encoding]::UTF8.GetBytes($Code)
$md5 = [System.Security.Cryptography.MD5]::Create()
$Hash = [BitConverter]::ToString($md5.ComputeHash($Bytes)).Replace("-", "").ToLower()
Write-Host "MD5: $Hash"
```

#### 方法二：保存为文件验证

```powershell
# 保存代码到临时文件
$Code | Out-File -FilePath "temp.java" -Encoding UTF8

# 计算文件 MD5
Get-FileHash -Path "temp.java" -Algorithm MD5
```

#### 方法三：在线验证

访问：https://www.md5hashgenerator.com/

## 📋 MD5 校验原理

### 为什么需要 MD5？

- ✅ 确保 AI 输出的代码与原代码完全一致
- ✅ 防止代码复制过程中出现遗漏或修改
- ✅ 便于后续验证代码完整性

### 工作原理

- MD5 是一种哈希算法，相同内容一定会生成相同的哈希值
- 即使只有一个字符不同，MD5 值也会完全不同
- 哈希值长度固定为 32 个十六进制字符

## 💡 使用技巧

### 1. 如何找到 Controller 类

根据 API URL 路径，在项目中搜索对应的 `@RequestMapping` 或 `@GetMapping` 注解。

### 2. 按依赖顺序提取

正确的提取顺序是：
1. **DTO/Entity** - 数据传输对象
2. **Repository** - 数据访问层
3. **Service** - 业务逻辑层
4. **Controller** - 控制器层（包含所有私有辅助方法）

### 3. 检查清单

提取完成后，确认以下内容：
- [ ] 所有 DTO 类已完整提取
- [ ] 所有 Repository 方法已包含
- [ ] Service 层代码完整
- [ ] Controller 包含所有私有辅助方法
- [ ] 每个代码块都有 MD5 校验值

## 🔧 自定义校验清单

如果您需要为其他文件生成校验清单，可以直接在 PowerShell 中运行：

```powershell
# 读取文件
$File = "mootdx-server\src\main\java\com\mootdx\server\controller\TdxDataImportController.java"
$Content = Get-Content -Path $File -Raw -Encoding UTF8

# 计算 MD5
$Bytes = [System.Text.Encoding]::UTF8.GetBytes($Content)
$md5 = [System.Security.Cryptography.MD5]::Create()
$Hash = [BitConverter]::ToString($md5.ComputeHash($Bytes)).Replace("-", "").ToLower()
Write-Host "MD5: $Hash"
```

## 📞 常见问题

### Q: AI 输出的代码和原代码的 MD5 不一致怎么办？
A: 请重新请求 AI 生成代码，并明确要求完整准确地复制。

### Q: 如何提取多个相关的接口？
A: 可以一次性列出所有需要的接口，AI 会按顺序提取。

### Q: 代码太长怎么办？
A: 如果代码太长，可以分段提取，但确保每段都有独立的 MD5 值。
