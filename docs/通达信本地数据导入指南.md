# 通达信本地数据导入指南

## 概述

本工具用于将通达信软件下载的本地K线数据文件解析并导入到数据库中，支持日线、1分钟线、5分钟线数据。

## 数据文件位置

通达信本地数据文件默认存储在安装目录的 `vipdoc` 文件夹下：

```
通达信安装目录\vipdoc\
├── sh\lday\          # 上海日线数据 (*.day)
├── sz\lday\          # 深圳日线数据 (*.day)
├── bj\lday\          # 北交所日线数据 (*.day)
├── sh\minline\       # 上海1分钟线 (*.lc1)
├── sz\minline\       # 深圳1分钟线 (*.lc1)
├── sh\fzline\        # 上海5分钟线 (*.lc5)
└── sz\fzline\        # 深圳5分钟线 (*.lc5)
```

## 数据文件格式

### 日线数据 (*.day)

每条记录32字节，小端序：

| 字节偏移 | 长度 | 字段 | 类型 | 说明 |
|---------|------|------|------|------|
| 00-03 | 4 | 日期 | int | YYYYMMDD格式 |
| 04-07 | 4 | 开盘价 | int | 实际价格×100 |
| 08-11 | 4 | 最高价 | int | 实际价格×100 |
| 12-15 | 4 | 最低价 | int | 实际价格×100 |
| 16-19 | 4 | 收盘价 | int | 实际价格×100 |
| 20-23 | 4 | 成交额 | float | 元 |
| 24-27 | 4 | 成交量 | int | 股数 |
| 28-31 | 4 | 保留 | int | - |

### 分钟线数据 (*.lc1 / *.lc5)

每条记录32字节，小端序：

| 字节偏移 | 长度 | 字段 | 类型 | 说明 |
|---------|------|------|------|------|
| 00-01 | 2 | 日期编码 | short | 特殊编码，需转换 |
| 02-03 | 2 | 分钟数 | short | 0点开始的分钟数 |
| 04-07 | 4 | 开盘价 | int | 实际价格×100 |
| 08-11 | 4 | 最高价 | int | 实际价格×100 |
| 12-15 | 4 | 最低价 | int | 实际价格×100 |
| 16-19 | 4 | 收盘价 | int | 实际价格×100 |
| 20-23 | 4 | 成交额 | float | 元 |
| 24-27 | 4 | 成交量 | int | 股数 |
| 28-31 | 4 | 保留 | int | - |

**日期编码转换公式**：
```java
year = (dateCode / 2048) + 2004;
month = (dateCode % 2048) / 100;
day = (dateCode % 2048) % 100;
```

## 使用方法

### 1. 命令行工具

```bash
cd mootdx-core
mvn exec:java -Dexec.mainClass="com.mootdx.localdata.TdxDataImportTool"
```

### 2. 配置文件

创建 `tdx-import.properties` 文件：

```properties
# 通达信安装目录
tdx.install.dir=C:\\new_tdx

# 数据库配置
db.url=jdbc:mysql://localhost:3306/mootdx?useSSL=false&serverTimezone=Asia/Shanghai
db.username=root
db.password=your_password
db.driver=com.mysql.cj.jdbc.Driver
```

### 3. 程序调用

```java
// 创建数据源
DataSource dataSource = createDataSource();

// 创建导入服务
TdxDataImportService importService = new TdxDataImportService(dataSource);

// 创建数据表
importService.createTableIfNotExists("DAY");
importService.createTableIfNotExists("MINUTE1");
importService.createTableIfNotExists("MINUTE5");

// 导入日线数据
TdxDataImportService.ImportStatistics stats = 
    importService.importDayData("C:\\new_tdx\\vipdoc\\sh\\lday", 1000);
System.out.println(stats);

// 导入5分钟线数据
stats = importService.importMinute5Data("C:\\new_tdx\\vipdoc\\sh\\fzline", 1000);
System.out.println(stats);
```

## 数据库表结构

### 日线数据表 (kline_day)

```sql
CREATE TABLE kline_day (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  stock_code VARCHAR(10) NOT NULL COMMENT '股票代码',
  market VARCHAR(2) NOT NULL COMMENT '市场(sh/sz/bj)',
  date VARCHAR(8) NOT NULL COMMENT '日期YYYYMMDD',
  open_price DECIMAL(10,2) COMMENT '开盘价',
  high_price DECIMAL(10,2) COMMENT '最高价',
  low_price DECIMAL(10,2) COMMENT '最低价',
  close_price DECIMAL(10,2) COMMENT '收盘价',
  volume BIGINT COMMENT '成交量(股)',
  amount BIGINT COMMENT '成交额(元)',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_stock_date (stock_code, market, date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='日线数据';
```

## 注意事项

1. **数据下载**：使用前需要在通达信软件中下载盘后数据
   - 菜单：系统 → 盘后数据下载
   - 选择需要下载的数据类型（日线、1分钟线、5分钟线）

2. **数据更新**：通达信数据文件是增量更新的，可以重复导入，已存在的数据会被更新

3. **复权处理**：本地数据文件存储的是原始未复权数据，复权计算需要额外处理

4. **性能优化**：
   - 建议使用批处理导入（默认1000条/批次）
   - 大批量导入时可适当增大批处理大小
   - 首次导入可能需要较长时间

5. **存储空间**：
   - 日线数据：约几百MB
   - 5分钟线数据：约几个GB
   - 1分钟线数据：约几十GB

## 相关类说明

### TdxLocalDataReader

数据文件读取器，提供以下方法：
- `readDayFile(String filePath)` - 读取日线文件
- `readMinute1File(String filePath)` - 读取1分钟线文件
- `readMinute5File(String filePath)` - 读取5分钟线文件
- `scanDataFiles(String directory, String extension)` - 扫描目录中的数据文件
- `extractStockCode(String fileName)` - 从文件名提取股票代码
- `extractMarketCode(String fileName)` - 从文件名提取市场代码

### TdxDataImportService

数据导入服务，提供以下方法：
- `importDayData(String directory, int batchSize)` - 批量导入日线数据
- `importMinute1Data(String directory, int batchSize)` - 批量导入1分钟线数据
- `importMinute5Data(String directory, int batchSize)` - 批量导入5分钟线数据
- `createTableIfNotExists(String dataType)` - 创建数据表
