## 通用说明

### 连接信息

- **默认端口**: 7709
- **Level-2端口**: 7727
- **默认服务器**: 180.153.18.170

### 协议通用规则

1. **字节序**: 所有多字节字段使用小端序 (Little-Endian)
2. **编码**: 股票代码使用ASCII编码，中文内容使用GBK编码
3. **校验和**: 部分请求需要计算校验和
4. **心跳**: 必须每30秒发送一次心跳包维持连接

### 标准响应头 (16字节)

所有响应都包含16字节的标准头部：

| 偏移 | 长度 | 字段名 | 说明 |
|------|------|--------|------|
| 0-3 | 4 | unknown1 | 未知 |
| 4-7 | 4 | unknown2 | 未知 |
| 8-11 | 4 | unknown3 | 未知 |
| 12-13 | 2 | zipsize | 压缩后数据大小 |
| 14-15 | 2 | unzipsize | 解压后数据大小 |

### 数据压缩

响应数据可能使用zlib压缩，需要解压：

```java
// Java解压示例
Inflater inflater = new Inflater();
inflater.setInput(compressedData);
byte[] result = new byte[unzipsize];
inflater.inflate(result);
inflater.end();
```

```python
# Python解压示例
import zlib
decompressed = zlib.decompress(compressed_data)
```

## 注意事项

1. **连接限制**: 不要频繁建立连接，建议使用连接池
2. **请求频率**: 避免过高频率请求，防止被封禁
3. **错误处理**: 做好超时和异常处理
4. **数据缓存**: 适当缓存数据，减少请求次数
