# 通达信成交明细接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取成交明细 (getTransactionData) |
| 命令码 | 0x0540 |
| pytdx对应 | `get_transaction_data()` |
| 功能描述 | 获取股票的逐笔成交数据 |

## 请求协议

### 数据包结构

**总长度**: 22字节 (12字节头部 + 10字节数据)

**字节序**: 小端序 (Little-Endian)

### 请求结构

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (22) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0540 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 股票代码，ASCII编码 |
| 14-15 | 2 | start | ushort | 起始位置 |
| 16-17 | 2 | count | ushort | 请求条数 |
| 18-21 | 4 | padding | bytes | 填充0 |

### 请求示例

获取600036的最新100笔成交:

```
完整数据包 (22 bytes):
16 00                    -- length: 22
XX                       -- checksum
01                       -- header: 0x01
40 05                    -- cmd: 0x0540
01 00                    -- market: 1 (上海)
36 30 30 30 33 36        -- code: "600036"
00 00                    -- start: 0
64 00                    -- count: 100
00 00 00 00              -- padding
```

## 响应协议

### 响应结构

**头部**: 16字节 (标准响应头)

**数据体**: 成交明细数据序列

数据体前2字节为记录数量，之后是成交记录。

### 成交记录结构 (16字节/条)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | time | ushort | 时间 (HHMM格式) |
| 2-3 | 2 | price | ushort | 价格 (实际值/100) |
| 4-7 | 4 | volume | int | 成交量 |
| 8-9 | 2 | buyOrder | ushort | 买委托号 |
| 10-11 | 2 | sellOrder | ushort | 卖委托号 |
| 12-13 | 2 | bs | ushort | 买卖方向 (0=买, 1=卖, 2=平) |
| 14-15 | 2 | reserved | ushort | 保留 |

### 买卖方向

| 值 | 含义 |
|------|------|
| 0 | 买盘 (主动买入) |
| 1 | 卖盘 (主动卖出) |
| 2 | 中性盘 (平盘) |

## 注意事项

1. **实时性**: 成交明细是实时数据
2. **分页**: 需要分页查询获取完整数据
3. **时间**: 时间格式为HHMM（如1430表示14:30）
4. **价格**: 价格需要除以100得到实际值
