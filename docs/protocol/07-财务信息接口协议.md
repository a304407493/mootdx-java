# 通达信财务信息接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取财务信息 (getFinanceInfo) |
| 命令码 | 0x0547 (或类似) |
| pytdx对应 | `get_finance_info()` |
| 功能描述 | 获取股票的财务数据 |

## 请求协议

### 数据包结构

**总长度**: 18字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 股票代码 |
| 14-17 | 4 | padding | bytes | 填充0 |

## 响应协议

### 财务数据结构

财务数据包含多个字段，主要包括：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 每股收益 | float | EPS |
| 每股净资产 | float | BPS |
| 净资产收益率 | float | ROE |
| 总股本 | long | 总股本 |
| 流通股本 | long | 流通股本 |
| 总市值 | float | 总市值 |
| 流通市值 | float | 流通市值 |
| 主营业务收入 | float | 主营收入 |
| 主营业务利润 | float | 主营利润 |
| 净利润 | float | 净利润 |
| 资产负债率 | float | 负债率 |
| 流动比率 | float | 流动比率 |
| 速动比率 | float | 速动比率 |
| 存货周转率 | float | 存货周转 |
| 应收账款周转率 | float | 应收周转 |

## 注意事项

1. **数据频率**: 财务数据按季度更新
2. **单位**: 金额单位通常为万元或亿元
3. **精度**: 部分字段可能需要除以100或10000
4. **缓存**: 财务数据变化较少，适合长期缓存
