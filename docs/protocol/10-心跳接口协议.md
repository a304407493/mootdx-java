# 通达信心跳接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 心跳/保活 (heartbeat) |
| 命令码 | 0x0801 |
| pytdx对应 | 自动发送 |
| 功能描述 | 维持与TDX服务器的连接 |

## 请求协议

### 数据包结构

**总长度**: 16字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (16) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x00) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0801 |
| 6-15 | 10 | payload | bytes | 填充0 |

### 请求示例

```
完整数据包 (16 bytes):
10 00                    -- length: 16
XX                       -- checksum
00                       -- header: 0x00 (心跳使用0x00)
01 08                    -- cmd: 0x0801
00 00 00 00 00 00 00 00 00 00  -- payload
```

## 发送频率

**必须每30秒发送一次**，否则服务器会断开连接。

```java
// 心跳定时器
scheduler.scheduleAtFixedRate(() -> {
    sendHeartbeat();
}, 30, 30, TimeUnit.SECONDS);
```

## 响应协议

心跳通常不需要等待响应，发送即可。

## 注意事项

1. **频率**: 必须每30秒发送一次
2. **协议头**: 心跳使用0x00，不是0x01
3. **自动重连**: 如果连接断开，需要重新建立连接
