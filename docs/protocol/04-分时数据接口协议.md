# 通达信分时数据接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取分时数据 (getMinuteTimeData) |
| 命令码 | 0x053c |
| pytdx对应 | `get_minute_time_data()` |
| 功能描述 | 获取股票当日的分时走势数据 |

## 请求协议

### 数据包结构

**总长度**: 18字节 (12字节头部 + 6字节数据)

**字节序**: 小端序 (Little-Endian)

### 请求结构

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (18) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x053c |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 股票代码，ASCII编码 |
| 14-17 | 4 | padding | bytes | 填充0 |

### 请求示例

获取600036的分时数据:

```
完整数据包 (18 bytes):
12 00                    -- length: 18
XX                       -- checksum
01                       -- header: 0x01
3C 05                    -- cmd: 0x053c
01 00                    -- market: 1 (上海)
36 30 30 30 33 36        -- code: "600036"
00 00 00 00              -- padding
```

## 响应协议

### 响应结构

**头部**: 16字节 (标准响应头)

**数据体**: 分时数据序列

数据体前2字节为数据点数量，之后是分时记录。

### 分时记录结构 (8字节/条)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-3 | 4 | price | int | 价格 (实际值/100) |
| 4-7 | 4 | volume | int | 成交量 |

### 时间计算

分时数据按分钟顺序排列，从开盘时间开始：

```
时间 = 9:30 + (索引 * 1分钟)

// 例如:
索引0: 9:30
索引1: 9:31
索引2: 9:32
...
```

## 注意事项

1. **交易时间**: 只返回交易时间内的数据（9:30-11:30, 13:00-15:00）
2. **实时性**: 数据是实时的，会随着交易不断更新
3. **价格**: 价格需要除以100得到实际值
