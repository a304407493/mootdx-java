# 通达信行情接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取实时行情 (getQuote) |
| 命令码 | 0x053e |
| pytdx对应 | `get_security_quotes()` |
| 功能描述 | 获取一只或多只股票的实时行情数据 |

## 请求协议

### 数据包结构

**总长度**: 29字节 (22字节头部 + 7字节股票数据)

**字节序**: 小端序 (Little-Endian)

### 头部结构 (22字节)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | magic | ushort | 固定值 0x010c |
| 2-5 | 4 | unknown1 | uint | 固定值 0x02006320 |
| 6-7 | 2 | pkgdatalen1 | ushort | 数据长度 = 股票数据长度 + 12 |
| 8-9 | 2 | pkgdatalen2 | ushort | 同上，重复 |
| 10-13 | 4 | cmd | uint | 命令码 = 0x50000 + 0x053e = 0x5053e |
| 14-15 | 2 | reserved1 | ushort | 保留，填0 |
| 16-17 | 2 | reserved2 | ushort | 保留，填0 |
| 18-19 | 2 | padding | ushort | 填充，填0 |
| 20-21 | 2 | stock_count | ushort | 股票数量 |

### 股票数据 (7字节/只)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0 | 1 | market | byte | 市场代码 (0=深圳, 1=上海) |
| 1-6 | 6 | code | string | 股票代码，ASCII编码，不足6位右补0 |

### 请求示例

获取单只股票 (600036 招商银行):

```
完整数据包 (29 bytes):
0C 01                    -- magic: 0x010c
20 63 00 02              -- unknown1: 0x02006320
13 00                    -- pkgdatalen1: 19
13 00                    -- pkgdatalen2: 19
3E 05 05 00              -- cmd: 0x5053e (0x50000 + 0x053e)
00 00                    -- reserved1
00 00                    -- reserved2
00 00                    -- padding
01 00                    -- stock_count: 1
01                       -- market: 1 (上海)
36 30 30 30 33 36        -- code: "600036"
```

### Python struct格式

```python
import struct

# 头部格式
header_fmt = "<HIHHIIHH"  # 22字节
# H: magic (2)
# I: unknown1 (4)
# H: pkgdatalen1 (2)
# H: pkgdatalen2 (2)
# I: cmd (4) - 注意这里是I不是H，因为pytdx使用0x50000 + cmd
# H: reserved1 (2)
# H: reserved2 (2)
# H: stock_count (2)

# 股票数据格式
stock_fmt = "<B6s"  # 7字节
# B: market (1)
# 6s: code (6)
```

## 响应协议

### 响应结构

**头部**: 16字节 (标准响应头)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-3 | 4 | unknown1 | uint | 未知 |
| 4-7 | 4 | unknown2 | uint | 未知 |
| 8-11 | 4 | unknown3 | uint | 未知 |
| 12-13 | 2 | zipsize | ushort | 压缩后数据大小 |
| 14-15 | 2 | unzipsize | ushort | 解压后数据大小 |

**数据体**: 股票行情数据 (每只64字节)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | market | ushort | 市场代码 |
| 2-7 | 6 | code | string | 股票代码 |
| 8-9 | 2 | active1 | ushort | 活跃度 |
| 10-13 | 4 | price | int | 最新价 (实际值/100) |
| 14-17 | 4 | last_close | int | 昨收 (实际值/100) |
| 18-21 | 4 | open | int | 开盘价 (实际值/100) |
| 22-25 | 4 | high | int | 最高价 (实际值/100) |
| 26-29 | 4 | low | int | 最低价 (实际值/100) |
| ... | ... | ... | ... | 更多字段 |

### 响应示例

```
响应头部 (16 bytes):
21 43 65 87              -- unknown1
0C 02 63 62              -- unknown2
00 04 3E 05              -- unknown3
51 00                    -- zipsize: 81
51 00                    -- unzipsize: 81

数据体 (81 bytes，单只股票):
01 00                    -- market: 1
36 30 30 30 33 36        -- code: "600036"
E6 0A                    -- active1: 2790
...
```

// 示例: 解析价格

## 批量请求

单次请求最多支持80只股票:

```java
// 计算包长度
int stockCount = symbols.size();
int stockDataLen = stockCount * 7;
int pkgDataLen = stockDataLen + 12;
int totalLen = 22 + stockDataLen;  // 头部22字节 + 股票数据
```

## 注意事项

1. **字节序**: 所有多字节字段使用小端序
2. **编码**: 股票代码使用ASCII编码
3. **填充**: 股票代码不足6位需要右补0
4. **命令码**: pytdx格式使用 `0x50000 + cmd`
5. **响应**: 可能需要zlib解压

## 参考代码

### Java实现参考

```java
// 构建请求
ByteBuffer packet = ByteBuffer.allocate(totalLen);
packet.order(ByteOrder.LITTLE_ENDIAN);

packet.putShort((short) 0x010c);           // [0-1] magic
packet.putInt(0x02006320);                 // [2-5] unknown1
packet.putShort((short) pkgDataLen);       // [6-7] pkgdatalen1
packet.putShort((short) pkgDataLen);       // [8-9] pkgdatalen2
packet.putInt(0x50000 + 0x053e);           // [10-13] cmd
packet.putShort((short) 0);                // [14-15] reserved1
packet.putShort((short) 0);                // [16-17] reserved2
packet.putShort((short) 0);                // [18-19] padding
packet.putShort((short) stockCount);       // [20-21] stock_count

// 股票数据
packet.put((byte) market);                 // market
byte[] codeBytes = code.getBytes();
packet.put(codeBytes, 0, Math.min(codeBytes.length, 6));  // code
```

### Python实现参考

```python
import struct

# 构建请求
stock_count = 1
market = 1
code = b'600036'

stock_data_len = stock_count * 7
pkg_data_len = stock_data_len + 12

header = struct.pack('<HIHHIIHH',
    0x010c,        # magic
    0x02006320,    # unknown1
    pkg_data_len,  # pkgdatalen1
    pkg_data_len,  # pkgdatalen2
    0x5053e,       # cmd (0x50000 + 0x053e)
    0,             # reserved1
    0,             # reserved2
    stock_count    # stock_count
)

stock_data = struct.pack('<B6s', market, code)
packet = header + stock_data
```
