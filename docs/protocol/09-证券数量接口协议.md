# 通达信证券数量接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取证券数量 (getSecurityCount) |
| 命令码 | 0x0546 |
| pytdx对应 | `get_security_count()` |
| 功能描述 | 获取指定市场的证券总数 |

## 请求协议

### 数据包结构

**总长度**: 12字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (12) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0546 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-11 | 4 | padding | bytes | 填充0 |

### 请求示例

获取上海市场的证券数量:

```
完整数据包 (12 bytes):
0C 00                    -- length: 12
XX                       -- checksum
01                       -- header: 0x01
46 05                    -- cmd: 0x0546
01 00                    -- market: 1 (上海)
00 00 00 00              -- padding
```

## 响应协议

### 响应结构

**数据体**: 4字节整数，表示证券数量

```
数据体 (4 bytes):
XX XX XX XX              -- count: 证券数量
```

## 市场代码

| 代码 | 市场 |
|------|------|
| 0 | 深圳 |
| 1 | 上海 |
| 2 | 北京 |
| 3 | 扩展市场 |

## 应用场景

1. **分页计算**: 获取总数后计算分页参数
2. **数据同步**: 判断是否需要全量同步
3. **监控**: 监控市场扩容情况
