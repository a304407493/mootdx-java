# 通达信公司信息接口协议文档

## 接口概述

公司信息接口包含两个子接口：
1. **获取公司信息分类** (getCompanyInfoCategory)
2. **获取公司信息内容** (getCompanyInfo)

## 接口1: 获取公司信息分类

### 基本信息

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取公司信息分类 |
| 命令码 | 0x0541 |
| pytdx对应 | `get_company_info_category()` |
| 功能描述 | 获取公司信息的分类列表 |

### 请求协议

**总长度**: 18字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (18) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0541 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 股票代码 |
| 14-17 | 4 | padding | bytes | 填充0 |

### 响应协议

**数据体**: 分类列表

每个分类包含：
- 分类名称 (字符串)
- 分类代码 (用于获取内容)

## 接口2: 获取公司信息内容

### 基本信息

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取公司信息内容 |
| 命令码 | 0x0542 |
| pytdx对应 | `get_company_info()` |
| 功能描述 | 获取指定分类的公司信息内容 |

### 请求协议

**总长度**: 24字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (24) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0542 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 股票代码 |
| 14-17 | 4 | category | uint | 分类代码 |
| 18-19 | 2 | start | ushort | 起始位置 |
| 20-21 | 2 | count | ushort | 请求长度 |
| 22-23 | 2 | padding | bytes | 填充0 |

### 响应协议

**数据体**: 信息内容 (文本格式，通常为GBK编码)

## 常见信息分类

| 分类代码 | 分类名称 |
|----------|----------|
| 1 | 公司概况 |
| 2 | 公司高管 |
| 3 | 公司公告 |
| 4 | 财务分析 |
| 5 | 股东研究 |
| 6 | 股本结构 |
| 7 | 资本运作 |
| 8 | 分红融资 |
| 9 | 行业分析 |
| 10 | 经营分析 |

## 注意事项

1. **编码**: 信息内容通常使用GBK编码
2. **分页**: 长内容需要分页获取
3. **缓存**: 公司信息变化较少，适合缓存
