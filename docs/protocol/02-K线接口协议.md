# 通达信K线接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取K线数据 (getKLine) |
| 命令码 | 0x052d |
| pytdx对应 | `get_security_bars()` |
| 功能描述 | 获取股票的历史K线数据（日线、分钟线等） |

## 请求协议

### 数据包结构

**总长度**: 36字节 (完整协议头)

**字节序**: 小端序 (Little-Endian)

### 完整请求结构 (36字节)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | magic | ushort | 固定值 0x010c |
| 2-5 | 4 | unknown1 | uint | 固定值 0x01016408 |
| 6-7 | 2 | pkgdatalen1 | ushort | 固定值 0x001c |
| 8-9 | 2 | pkgdatalen2 | ushort | 固定值 0x001c |
| 10-11 | 2 | cmd | ushort | 命令码 0x052d |
| 12-13 | 2 | market | ushort | 市场代码 (0=深圳, 1=上海) |
| 14-19 | 6 | code | string | 股票代码，ASCII编码 |
| 20-21 | 2 | category | ushort | K线周期 (见下表) |
| 22-23 | 2 | unknown2 | ushort | 固定值 1 |
| 24-25 | 2 | start | ushort | 起始位置 (0表示最新) |
| 26-27 | 2 | count | ushort | 请求条数 (最大800) |
| 28-31 | 4 | unknown3 | uint | 固定值 0 |
| 32-35 | 4 | unknown4 | uint | 固定值 0 |

### K线周期代码

| 代码 | 周期 |
|------|------|
| 0 | 5分钟 |
| 1 | 15分钟 |
| 2 | 30分钟 |
| 3 | 1小时 |
| 4 | 日线 (pytdx不使用) |
| 5 | 周线 |
| 6 | 月线 |
| 8 | 1分钟 |
| 9 | 日线 (pytdx使用) |
| 10 | 季线 |
| 11 | 年线 |

### 请求示例

获取600036的日线数据，最新10条:

```
完整数据包 (36 bytes):
0C 01                    -- magic: 0x010c
08 64 01 01              -- unknown1: 0x01016408
1C 00                    -- pkgdatalen1: 28
1C 00                    -- pkgdatalen2: 28
2D 05                    -- cmd: 0x052d
01 00                    -- market: 1 (上海)
36 30 30 30 33 36        -- code: "600036"
09 00                    -- category: 9 (日线)
01 00                    -- unknown2: 1
00 00                    -- start: 0
0A 00                    -- count: 10
00 00 00 00              -- unknown3: 0
00 00 00 00              -- unknown4: 0
```

### Python struct格式

```python
import struct

# K线请求格式
kline_fmt = "<HIHHHH6sHHHHIIH"
# H: magic (2) - 0x010c
# I: unknown1 (4) - 0x01016408
# H: pkgdatalen1 (2) - 0x001c
# H: pkgdatalen2 (2) - 0x001c
# H: cmd (2) - 0x052d
# H: market (2)
# 6s: code (6)
# H: category (2)
# H: unknown2 (2) - 1
# H: start (2)
# H: count (2)
# I: unknown3 (4) - 0
# I: unknown4 (4) - 0
# H: padding (2) - 0 (struct自动对齐)

packet = struct.pack(kline_fmt,
    0x010c,        # magic
    0x01016408,    # unknown1
    0x001c,        # pkgdatalen1
    0x001c,        # pkgdatalen2
    0x052d,        # cmd
    market,        # market
    code.encode(), # code
    category,      # category
    1,             # unknown2
    start,         # start
    count,         # count
    0,             # unknown3
    0,             # unknown4
    0              # padding
)
```

## 响应协议

### 响应结构

**头部**: 16字节 (标准响应头)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-3 | 4 | unknown1 | uint | 未知 |
| 4-7 | 4 | unknown2 | uint | 未知 |
| 8-11 | 4 | unknown3 | uint | 未知 |
| 12-13 | 2 | zipsize | ushort | 压缩后数据大小 |
| 14-15 | 2 | unzipsize | ushort | 解压后数据大小 |

**数据体**: K线数据序列

数据体前2字节为股票数量，之后是K线记录。

### K线记录结构 (32字节/条)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | zipday | ushort | 压缩日期 (从2004-01-01开始的天数) |
| 2-5 | 4 | open | int | 开盘价 (差值编码) |
| 6-9 | 4 | high | int | 最高价 (差值编码) |
| 10-13 | 4 | low | int | 最低价 (差值编码) |
| 14-17 | 4 | close | int | 收盘价 (差值编码) |
| 18-21 | 4 | amount | float | 成交额 |
| 22-25 | 4 | volume | int | 成交量 |
| 26-29 | 4 | reserved | int | 保留 |

### 差值编码说明

K线价格使用差值编码存储：

```
第一条记录:
  open = raw_open / 100
  high = open + (raw_high / 100)
  low = open + (raw_low / 100)
  close = open + (raw_close / 100)

后续记录:
  open = prev_close + (raw_open / 100)
  high = open + (raw_high / 100)
  low = open + (raw_low / 100)
  close = open + (raw_close / 100)
```

### 日期计算

```java
// zipday是从2004-01-01开始的天数
LocalDate baseDate = LocalDate.of(2004, 1, 1);
LocalDate date = baseDate.plusDays(zipday);
```

### 分钟线特殊处理

分钟线数据包含时间信息：

```
zipday: 日期 (从2004-01-01开始的天数)
tminutes: 从当天0点开始经过的分钟数

// 计算具体时间
int hour = tminutes / 60;
int minute = tminutes % 60;
```

```
数据体:

```

## 注意事项

1. **字节序**: 所有多字节字段使用小端序
2. **编码**: 股票代码使用ASCII编码
3. **差值编码**: 价格使用差值编码，需要逐条计算
4. **日期**: 使用从2004-01-01开始的天数
5. **响应**: 可能需要zlib解压
6. **连接**: 服务器可能在每次请求后断开连接

## 参考代码

### Java实现参考

```java
// 构建K线请求
ByteBuffer payload = ByteBuffer.allocate(36);
payload.order(ByteOrder.LITTLE_ENDIAN);

payload.putShort((short) 0x010c);           // [0-1] magic
payload.putInt(0x01016408);                 // [2-5] unknown1
payload.putShort((short) 0x001c);           // [6-7] pkgdatalen1
payload.putShort((short) 0x001c);           // [8-9] pkgdatalen2
payload.putShort(TdxProtocol.CMD_GET_KLINE); // [10-11] cmd
payload.putShort((short) market);           // [12-13] market
ByteUtils.writeString(payload, code, 6);    // [14-19] code
payload.putShort((short) category);         // [20-21] category
payload.putShort((short) 1);                // [22-23] unknown2
payload.putShort((short) start);            // [24-25] start
payload.putShort((short) count);            // [26-27] count
payload.putInt(0);                          // [28-31] unknown3
payload.putInt(0);                          // [32-35] unknown4
```

### 解析K线数据

```java
// 解析单条K线
short zipday = buffer.readShort();
int rawOpen = buffer.readInt();
int rawHigh = buffer.readInt();
int rawLow = buffer.readInt();
int rawClose = buffer.readInt();
float amount = buffer.readFloat();
int volume = buffer.readInt();
buffer.skipBytes(4);  // reserved

// 计算实际日期
LocalDate date = LocalDate.of(2004, 1, 1).plusDays(zipday);

// 计算实际价格 (第一条记录)
double open = rawOpen / 100.0;
double high = open + (rawHigh / 100.0);
double low = open + (rawLow / 100.0);
double close = open + (rawClose / 100.0);
```
