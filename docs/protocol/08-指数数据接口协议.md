# 通达信指数数据接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取指数数据 (getIndex) |
| 命令码 | 0x0543 |
| pytdx对应 | `get_index()` |
| 功能描述 | 获取指数的成分股数据 |

## 请求协议

### 数据包结构

**总长度**: 18字节

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (18) |
| 2 | 1 | checksum | byte | 校验和 |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0543 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-13 | 6 | code | string | 指数代码 |
| 14-17 | 4 | padding | bytes | 填充0 |

### 常见指数代码

| 代码 | 名称 |
|------|------|
| 000001 | 上证指数 |
| 000002 | A股指数 |
| 000003 | B股指数 |
| 000016 | 上证50 |
| 000300 | 沪深300 |
| 399001 | 深证成指 |
| 399006 | 创业板指 |
| 399005 | 中小板指 |

## 响应协议

### 响应结构

**数据体**: 成分股列表

每个成分股包含：
- 股票代码
- 股票名称
- 权重 (部分指数提供)

## 注意事项

1. **定期更新**: 指数成分股会定期调整
2. **权重**: 部分指数提供权重数据
3. **缓存**: 成分股变化不频繁，可缓存
