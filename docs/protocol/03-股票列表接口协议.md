# 通达信股票列表接口协议文档

## 接口概述

| 属性 | 值 |
|------|-----|
| 接口名称 | 获取股票列表 (getSecurityList) |
| 命令码 | 0x0451 |
| pytdx对应 | `get_security_list()` |
| 功能描述 | 获取指定市场的股票列表 |

## 请求协议

### 数据包结构

**总长度**: 20字节 (14字节头部 + 6字节数据)

**字节序**: 小端序 (Little-Endian)

### 请求结构

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | length | ushort | 包长度 (20) |
| 2 | 1 | checksum | byte | 校验和 (计算方式见下方) |
| 3 | 1 | header | byte | 协议头 (0x01) |
| 4-5 | 2 | cmd | ushort | 命令码 0x0451 |
| 6-7 | 2 | market | ushort | 市场代码 |
| 8-9 | 2 | start | ushort | 起始位置 |
| 10-19 | 10 | padding | bytes | 填充0 |

### 校验和计算

```java
// 校验和 = 从第3字节开始所有字节的和 % 256
byte checksum = 0;
for (int i = 3; i < packet.length; i++) {
    checksum += packet[i];
}
packet[2] = checksum;
```

### 请求示例

获取上海市场从位置0开始的股票列表:

```
完整数据包 (20 bytes):
14 00                    -- length: 20
XX                       -- checksum (计算得出)
01                       -- header: 0x01
51 04                    -- cmd: 0x0451
01 00                    -- market: 1 (上海)
00 00                    -- start: 0
00 00 00 00 00 00 00 00 00 00  -- padding
```

### Python struct格式

```python
import struct

# 股票列表请求格式
fmt = "<HBBHHH10s"
# H: length (2) - 20
# B: checksum (1) - 稍后计算
# B: header (1) - 0x01
# H: cmd (2) - 0x0451
# H: market (2)
# H: start (2)
# 10s: padding (10)

packet = struct.pack(fmt,
    20,            # length
    0,             # checksum (占位)
    0x01,          # header
    0x0451,        # cmd
    market,        # market
    start,         # start
    b'\x00' * 10   # padding
)

# 计算校验和
checksum = sum(packet[3:]) % 256
packet = packet[:2] + bytes([checksum]) + packet[3:]
```

## 响应协议

### 响应结构

**头部**: 16字节 (标准响应头)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-3 | 4 | unknown1 | uint | 未知 |
| 4-7 | 4 | unknown2 | uint | 未知 |
| 8-11 | 4 | unknown3 | uint | 未知 |
| 12-13 | 2 | zipsize | ushort | 压缩后数据大小 |
| 14-15 | 2 | unzipsize | ushort | 解压后数据大小 |

**数据体**: 股票列表数据

数据体前2字节为股票数量，之后是股票记录。

### 股票记录结构 (29字节/条)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-5 | 6 | code | string | 股票代码，ASCII编码 |
| 6 | 1 | unknown | byte | 未知 |
| 7-26 | 20 | name | string | 股票名称，GBK编码 |
| 27-28 | 2 | unknown | bytes | 未知 |

### 响应示例

```
响应头部 (16 bytes):
21 43 65 87              -- unknown1
0C 02 63 62              -- unknown2
00 04 51 04              -- unknown3
XX XX                    -- zipsize
XX XX                    -- unzipsize

数据体:
XX XX                    -- 股票数量

股票记录1 (29 bytes):
36 30 30 30 33 36        -- code: "600036"
00                       -- unknown
XX XX ...                -- name: "招商银行" (GBK编码)
XX XX                    -- unknown

股票记录2-...
```

## 市场代码

| 代码 | 市场 |
|------|------|
| 0 | 深圳 (SZ) |
| 1 | 上海 (SH) |
| 2 | 北京 (BJ) |
| 3 | 扩展市场 (期货、期权等) |

## 分页查询

由于股票数量较多，需要分页查询：

```java
// 分页查询示例
int market = 1;  // 上海
int start = 0;
int pageSize = 1000;

while (true) {
    List<Stock> stocks = getSecurityList(market, start);
    if (stocks.isEmpty()) break;
    
    // 处理股票列表
    processStocks(stocks);
    
    // 下一页
    start += stocks.size();
    
    // 如果返回数量小于页大小，说明已经到最后
    if (stocks.size() < pageSize) break;
}
```

## 注意事项

1. **字节序**: 所有多字节字段使用小端序
2. **编码**: 股票代码使用ASCII编码，股票名称使用GBK编码
3. **校验和**: 请求包需要计算校验和
4. **分页**: 需要分页查询获取完整列表
5. **响应**: 可能需要zlib解压

## 参考代码

### Java实现参考

```java
// 构建股票列表请求
ByteBuffer buffer = ByteBuffer.allocate(20);
buffer.order(ByteOrder.LITTLE_ENDIAN);

buffer.putShort((short) 20);           // [0-1] length
buffer.put((byte) 0);                   // [2] checksum (占位)
buffer.put((byte) 0x01);                // [3] header
buffer.putShort(TdxProtocol.CMD_GET_STOCK_LIST);  // [4-5] cmd
buffer.putShort((short) market);        // [6-7] market
buffer.putShort((short) start);         // [8-9] start
// [10-19] padding (自动填充0)

byte[] packet = buffer.array();

// 计算校验和
byte checksum = 0;
for (int i = 3; i < packet.length; i++) {
    checksum += packet[i];
}
packet[2] = checksum;
```

### 解析股票列表

```java
// 解析股票记录
String code = readString(buffer, 6);    // ASCII编码
buffer.skipBytes(1);                     // unknown
String name = readGbkString(buffer, 20); // GBK编码
buffer.skipBytes(2);                     // unknown

System.out.println("Code: " + code + ", Name: " + name);
```
