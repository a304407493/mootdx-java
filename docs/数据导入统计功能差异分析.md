## 问题描述

- 数据库K线总数显示不正确
- 上海日线、深圳日线、北京日线显示为0
- 分钟线文件统计显示为0

```java
private int countFiles(String directory, String extension) {
    File dir = new File(directory);
    if (!dir.exists() || !dir.isDirectory()) {
        return 0;
    }
    File[] files = dir.listFiles((d, name) -> name.toLowerCase().endsWith(extension));
    return files != null ? files.length : 0;
}
```

### 4. calculateTotalSize 方法（关键差异）

#### 原项目代码
**文件**: `mootdx-server/src/main/java/com/mootdx/server/controller/TdxDataImportController.java`
**行号**: 439-455

```java
private long calculateTotalSize(String baseDir, String extension) {
    long totalSize = 0;
    File dir = new File(baseDir);
    if (dir.exists() && dir.isDirectory()) {
        File[] files = dir.listFiles();
        if (files != null) {
            for (File file : files) {
                if (file.isFile() && file.getName().toLowerCase().endsWith(extension)) {
                    totalSize += file.length();
                } else if (file.isDirectory()) {
                    totalSize += calculateTotalSize(file.getAbsolutePath(), extension);  // 递归子目录
                }
            }
        }
    }
    return totalSize;
}
```

#### 当前项目代码
**文件**: `javaTdx/src/main/java/com/example/tdx/controller/TdxDataImportController.java`
**行号**: 485-494

```java
private long calculateTotalSize(String dirPath, String extension) {
    File dir = new File(dirPath);
    if (!dir.exists() || !dir.isDirectory()) return 0;
    File[] files = dir.listFiles((d, name) -> name.toLowerCase().endsWith(extension));
    if (files == null) return 0;
    return Arrays.stream(files).mapToLong(File::length).sum();  // 不递归子目录
}
```

**差异分析**: 
- ❌ **关键差异**：原项目递归遍历子目录，当前项目只统计当前目录
- 这可能导致统计的大小不正确，但不影响文件数量统计

## 可能的问题原因

### 问题1：文件路径分隔符
原项目使用 `\\` 作为路径分隔符，在Windows上应该能正常工作。但需要确认 `TDX_INSTALL_DIR` 目录是否存在。

### 问题2：数据返回格式
虽然后端已改为返回 `ApiResponse`，但需要确认：
1. 前端是否正确处理了 `res.data.data`
2. 网络请求是否成功

### 问题3：目录不存在
如果通达信安装目录 `C:\new_tdx` 不存在或结构不同，会导致统计为0。

---

## 建议的修复步骤

1. **添加日志输出** - 在 `getStatistics()` 方法中添加详细日志，确认文件路径和统计结果
2. **检查目录存在性** - 确认 `C:\new_tdx` 目录及子目录是否存在
3. **调试前端** - 在浏览器开发者工具中检查网络请求返回的数据
4. **修复 calculateTotalSize** - 如果需要递归统计，修复该方法
