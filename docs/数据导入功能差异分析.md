### 1.2 Service层差异

#### 原项目 (mootdx-server)
**文件**: `mootdx-server/src/main/java/com/mootdx/server/service/TdxDataImportService.java`

**核心功能**:
1. **高性能导入** (L110-180)
   - 使用线程池并行处理文件 (THREAD_POOL_SIZE=4)
   - 批量插入优化 (BATCH_SIZE=2000)
   - 独立事务管理

2. **数据比对功能** (L250-320)
   - `compareDayData()`: 日线数据差异比对
   - `compareMinuteData()`: 分钟线数据差异比对
   - 返回差异类型: NEW(新增), MODIFIED(修改), SAME(相同)

3. **多种数据类型支持**:
   - 日线数据导入 (L110-180)
   - 分钟线数据导入 (L330-400)
   - 板块数据导入 (L400-480)
   - 备注数据导入 (L480-550)

4. **导入类型枚举** (L69-73):
   ```java
   public enum ImportType {
       FULL,       // 全量导入
       INCREMENTAL, // 增量导入
       DIFFERENTIAL // 差异导入
   }
   ```

#### javaTdx项目
**文件**: `javaTdx/src/main/java/com/example/tdx/service/TdxDataImportService.java`

**缺失功能**:
1. ❌ 多线程并行处理 (原项目使用ExecutorService)
2. ❌ 分钟线数据导入方法
3. ❌ 备注数据导入方法
4. ❌ 数据比对功能 (compareDayData, compareMinuteData)
5. ❌ 获取最新交易日期方法 (getLatestTradeDate)

**性能差异**:
- 原项目: BATCH_SIZE=2000, 4线程并行
- javaTdx: BATCH_SIZE=1000, 单线程处理

## 二、前端功能差异

### 2.1 原项目 (mootdx-server)
**文件**: `mootdx-server/src/main/resources/static/tdx-import.html`

**页面布局**:
1. **顶部统计卡片** (10个统计项)
   - 上海日线数据、深圳日线数据、北交所日线数据
   - 上海1分钟线、深圳1分钟线
   - 上海5分钟线、深圳5分钟线
   - 系统板块、自定义板块
   - 备注数据

2. **Tab切换** (10个Tab)
   - 上海日线、深圳日线、北交所日线
   - 上海1分钟、深圳1分钟
   - 上海5分钟、深圳5分钟
   - 系统板块、自定义板块
   - 备注数据

3. **每个Tab内容**:
   - 工具栏：全选/全不选、已选择计数、导入类型选择、比对差异按钮、导入选中按钮
   - 文件列表：显示文件信息、数据库对比信息（记录数、最新日期、差异数量）、状态标记
   - 每个文件项有复选框、预览按钮

**功能特性**:
1. **文件状态标记** (CSS类: item-new/item-diff/item-sync)
   - 绿色背景 = 新增 (NEW)
   - 橙色背景 = 有差异 (DIFF)
   - 蓝色背景 = 已同步 (SYNC)

2. **数据库对比信息显示**:
   ```html
   <div class="db-info">
       数据库: ${file.dbRecordCount} 条
       | 最新: ${file.dbLatestDate}
       | 差异: 文件多 ${file.diffCount} 条
   </div>
   ```

3. **批量比对差异** (`compareSelected()` 函数):
   - 选择单个文件进行比对
   - 显示新增/修改/相同记录数统计
   - 显示差异详情表格

4. **导入进度条**:
   - 进度条动画
   - 实时显示导入进度
   - 结果显示面板

5. **预览功能**:
   - 弹出模态框
   - 显示前5条和后5条数据
   - 支持日线、分钟线、板块、备注数据

### 2.2 javaTdx项目
**文件**: `javaTdx/frontend/src/views/TdxDataImport.vue`

**当前实现**:
1. **统计信息展示** (4个统计项)
   - 数据库K线总数、上海日线、深圳日线、北京日线
   - ❌ 缺少：分钟线统计、板块统计、备注数据统计

2. **卡片布局** (非Tab方式)
   - 日线数据导入卡片
   - 板块数据导入卡片
   - 分钟线数据导入卡片
   - 备注数据导入卡片

3. **已实现功能**:
   - ✅ 日线数据导入 (扫描、导入、预览、比对)
   - ✅ 板块数据导入 (扫描、导入、预览)
   - ✅ 分钟线数据导入 (1分钟/5分钟)
   - ✅ 备注数据导入
   - ✅ 文件预览功能
   - ✅ 数据比对功能 (每行有比对按钮)

**与原项目的差异**:

| 功能 | 原项目 | javaTdx | 状态 |
|------|--------|---------|------|
| 统计卡片 | 10个 | 4个 | ❌ 缺少6个 |
| Tab切换 | 有 | 无 | ❌ 不同 |
| 文件状态标记 | 有 (颜色区分) | 无 | ❌ 缺少 |
| 数据库对比信息 | 有 (记录数/日期/差异) | 无 | ❌ 缺少 |
| 批量比对 | 有 (工具栏按钮) | 有 (每行按钮) | ✅ 类似 |
| 导入进度条 | 有 | 无 (只有日志) | ❌ 缺少 |
| 全选/全不选 | 有 | 有 (表格自带) | ✅ 有 |
| 导入类型选择 | 每个Tab都有 | 有 | ✅ 有 |

**主要缺失功能**:
1. ❌ **文件状态可视化**：原项目根据数据库对比结果显示不同颜色标记
2. ❌ **数据库对比信息**：原项目在文件列表中显示数据库记录数、最新日期、差异数量
3. ❌ **导入进度条**：原项目有可视化进度条，当前项目只有文本日志
4. ❌ **统计信息不完整**：缺少分钟线、板块、备注数据的统计卡片
