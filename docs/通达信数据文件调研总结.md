## 二、各类数据文件详细说明

### 2.1 K线数据

#### 日线数据 (.day)

**存储位置**:
- `vipdoc/sh/lday/` - 上海市场
- `vipdoc/sz/lday/` - 深圳市场
- `vipdoc/bj/lday/` - 北交所市场

**文件格式**:
- 每条记录: 32字节
- 字节序: 小端序 (Little-Endian)
- 价格存储: 实际价格 × 100 (整数)

**记录结构**:

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|-----|------|------|------|------|
| 00-03 | 4 | 日期 | int | YYYYMMDD |
| 04-07 | 4 | 开盘价 | int | 价格×100 |
| 08-11 | 4 | 最高价 | int | 价格×100 |
| 12-15 | 4 | 最低价 | int | 价格×100 |
| 16-19 | 4 | 收盘价 | int | 价格×100 |
| 20-23 | 4 | 成交额 | float | 元 |
| 24-27 | 4 | 成交量 | int | 股数 |
| 28-31 | 4 | 保留 | int | - |

**当前状态**: ✅ 已下载，共9,230个文件

#### 分钟线数据 (.lc1 / .lc5)

**存储位置**:
- `vipdoc/sh/minline/` - 上海1分钟线
- `vipdoc/sz/minline/` - 深圳1分钟线
- `vipdoc/sh/fzline/` - 上海5分钟线
- `vipdoc/sz/fzline/` - 深圳5分钟线

**文件格式**:
- 每条记录: 32字节
- 日期编码: 特殊格式，需转换

**日期编码转换公式**:
```java
year = (dateCode / 2048) + 2004;
month = (dateCode % 2048) / 100;
day = (dateCode % 2048) % 100;
```

**当前状态**: ❌ 未下载，需要手动下载

### 2.2 板块数据

#### 自定义板块 (.blk)

**存储位置**: `T0002/blocknew/`

**文件格式**:
- 格式: 文本文件
- 编码: GBK
- 内容: 每行一个股票代码

**代码格式**:
- `市场代码(1位) + 股票代码(6位)`
- 0 = 深圳
- 1 = 上海

**示例**:
```

0000001  // 深圳000001
```

## 四、缺失数据获取方法

### 4.1 分钟线数据下载

**操作步骤**:
1. 打开通达信软件
2. 菜单: **系统 → 盘后数据下载**
3. 勾选 **"1分钟线"** 和 **"5分钟线"**
4. 选择市场范围（上海/深圳）
5. 点击 **"开始下载"**

**注意事项**:
- 数据量巨大（1分钟线可能几十GB）
- 下载时间较长
- 建议分市场下载

### 4.2 财务数据下载

**操作步骤**:
1. 打开通达信软件
2. 菜单: **系统 → 专业财务数据下载**
3. 选择需要的财务数据类型
4. 点击下载

### 4.3 公告数据获取

**结论**: 通达信公告数据**不在本地存储**

**替代方案**:
1. **网络爬虫** - 从交易所官网抓取
2. **API接口** - 使用财经数据API
3. **第三方服务** - Wind、东方财富等
