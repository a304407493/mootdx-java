### 1.2 文件类型详细说明

#### K线数据文件 (.day / .lc1 / .lc5)

| 文件类型 | 扩展名 | 存储位置 | 记录大小 | 用途 |
|---------|--------|---------|---------|------|
| 日线数据 | .day | vipdoc/{sh,sz,bj}/lday/ | 32字节 | 日K线数据 |
| 1分钟线 | .lc1 | vipdoc/{sh,sz}/minline/ | 32字节 | 1分钟K线 |
| 5分钟线 | .lc5 | vipdoc/{sh,sz}/fzline/ | 32字节 | 5分钟K线 |

**数据格式**:
- 字节序: 小端序 (Little-Endian)
- 价格单位: 实际价格 × 100 (整数存储)
- 日期格式: YYYYMMDD (日线) / 特殊编码 (分钟线)

#### 板块数据文件 (.blk / block.dat)

| 文件类型 | 扩展名 | 存储位置 | 格式 | 用途 |
|---------|--------|---------|------|------|
| 自定义板块 | .blk | T0002/blocknew/ | 文本格式 | 用户自定义股票分组 |
| 系统板块 | block.dat | T0002/hq_cache/ | 二进制格式 | 行业/概念/地域分类 |

**自定义板块文件格式**:
- 格式: 文本文件，GBK编码
- 每行: 市场代码(1位) + 股票代码(6位)
- 示例: `0600000` = 上海600000

**系统板块文件格式**:
- 文件头: 384字节
- 板块个数: 2字节
- 每个板块: 2813字节，最多400只股票

#### 财务数据文件 (.fin / gpcw*)

| 文件类型 | 扩展名 | 存储位置 | 格式 | 用途 |
|---------|--------|---------|------|------|
| 个股财务 | .fin | T0002/finance/ | 二进制 | 单只股票财务历史 |
| 全市场财务 | gpcw* | vipdoc/cw/ | 二进制 | 全市场财务快照 |

**当前状态**: 本地未找到财务数据文件

## 二、各类数据文件详细说明

### 2.1 K线数据文件

#### 日线数据 (.day) 格式

每条记录32字节：

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|-----|------|------|------|------|
| 00-03 | 4 | 日期 | int | YYYYMMDD |
| 04-07 | 4 | 开盘价 | int | 价格×100 |
| 08-11 | 4 | 最高价 | int | 价格×100 |
| 12-15 | 4 | 最低价 | int | 价格×100 |
| 16-19 | 4 | 收盘价 | int | 价格×100 |
| 20-23 | 4 | 成交额 | float | 元 |
| 24-27 | 4 | 成交量 | int | 股数 |
| 28-31 | 4 | 保留 | int | - |

#### 分钟线数据 (.lc1 / .lc5) 格式

每条记录32字节：

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|-----|------|------|------|------|
| 00-01 | 2 | 日期编码 | short | 特殊编码 |
| 02-03 | 2 | 分钟数 | short | 0点开始 |
| 04-07 | 4 | 开盘价 | int | 价格×100 |
| 08-11 | 4 | 最高价 | int | 价格×100 |
| 12-15 | 4 | 最低价 | int | 价格×100 |
| 16-19 | 4 | 收盘价 | int | 价格×100 |
| 20-23 | 4 | 成交额 | float | 元 |
| 24-27 | 4 | 成交量 | int | 股数 |
| 28-31 | 4 | 保留 | int | - |

**日期编码转换公式**:
```java
year = (dateCode / 2048) + 2004;
month = (dateCode % 2048) / 100;
day = (dateCode % 2048) % 100;
```

### 2.2 板块数据文件

#### 自定义板块 (.blk) 格式

- **文件格式**: 文本文件
- **编码**: GBK
- **内容**: 每行一个股票代码
- **格式**: `市场代码(1位) + 股票代码(6位)`
  - 0 = 深圳
  - 1 = 上海

**示例**:
```
0600000  // 上海600000
0000001  // 深圳000001
```

#### 系统板块分类 (block.dat) 格式

- **文件头**: 384字节
- **板块数量**: 2字节 (偏移384-385)
- **每个板块**: 2813字节

**板块记录结构**:

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|-----|------|------|------|------|
| 00-08 | 9 | 板块名称 | char[9] | GBK编码 |
| 09-10 | 2 | 股票数量 | word | - |
| 11-12 | 2 | 板块级别 | word | - |
| 13-2812 | 2800 | 股票代码列表 | char[7]×400 | 每只股票7字节 |
