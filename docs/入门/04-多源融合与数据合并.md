## 一、为什么需要多源融合？

### 1.1 单个数据源的问题

```
新浪API返回的数据：
✓ 股票名称、当前价格、涨跌幅
✓ 五档盘口（买一卖一等）
✗ PE比率、PB比率
✗ 总市值、流通市值

东方财富API返回的数据：
✓ PE比率、PB比率
✓ 总市值、流通市值
✗ 五档盘口
✗ 实时价格可能延迟

问题：如何同时获取完整的数据？
答案：多源融合 (AGGREGATED)
```

### 1.2 多源融合的核心思想

```
┌─────────────────────────────────────────────────────────────────┐
│                      多源融合工作流程                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户请求                                                      │
│      ↓                                                          │
│   同时请求多个数据源                                             │
│      ↓                                                          │
│   ┌─────────┐  ┌─────────────┐  ┌─────────┐                    │
│   │  新浪   │  │  东方财富    │  │  腾讯   │                    │
│   │ 价格    │  │  PE/PB      │  │  其他   │                    │
│   └────┬────┘  └──────┬──────┘  └────┬────┘                    │
│        └──────────────┼──────────────┘                          │
│                       ↓                                         │
│              按字段优先级合并                                     │
│                       ↓                                         │
│   价格 ← 新浪的                                                  │
│   PE/PB ← 东方财富的                                             │
│   其他 ← 腾讯的                                                  │
│                       ↓                                         │
│              计算派生字段                                         │
│                       ↓                                         │
│              返回完整数据                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 二、多源融合的实现

### 2.1 核心类

**文件位置**: `AggregatedDataCollectorService.java`

### 2.2 采集策略

```java
// AggregatedDataCollectorService.java 第36-55行
public enum CollectionStrategy {
    FASTEST,       // 最快优先 - 使用第一个返回的数据
    MOST_COMPLETE, // 最全优先 - 合并所有数据源的数据
    FREE_FIRST,    // 免费优先 - 优先使用免费数据源
    SMART          // 智能路由 - 根据字段需求自动选择
}
```

### 2.3 最快优先策略 (FASTEST)

```java
// AggregatedDataCollectorService.java 第119-154行
private StockInfoDTO collectFastest(String stockCode, int timeoutMs) {
    // 1. 创建并行任务
    List<CompletableFuture<StockInfoDTO>> futures = new ArrayList<>();
    
    for (StockDataSource source : availableSources) {
        CompletableFuture<StockInfoDTO> future = CompletableFuture
            .supplyAsync(() -> source.collect(stockCode))
            .orTimeout(timeoutMs, TimeUnit.MILLISECONDS)
            .exceptionally(ex -> null);
        futures.add(future);
    }
    
    // 2. 等待第一个成功的结果
    for (CompletableFuture<StockInfoDTO> future : futures) {
        StockInfoDTO result = future.get();
        if (result != null) {
            return result;  // 返回第一个成功的
        }
    }
    
    return null;
}
```

**特点**：
- 同时请求所有数据源
- 哪个先返回用哪个
- 超时时间5秒
- 适合追求速度的场景

### 2.4 最全优先策略 (MOST_COMPLETE)

```java
// AggregatedDataCollectorService.java 第159-204行
private StockInfoDTO collectMostComplete(String stockCode, int timeoutMs) {
    // 1. 并行采集所有数据源
    Map<String, StockInfoDTO> results = new HashMap<>();
    
    for (StockDataSource source : availableSources) {
        try {
            StockInfoDTO data = source.collect(stockCode);
            if (data != null) {
                results.put(source.getSourceName(), data);
            }
        } catch (Exception e) {
            log.warn("数据源{}采集失败", source.getSourceName());
        }
    }
    
    // 2. 使用DataMergeService合并数据
    if (!results.isEmpty()) {
        return dataMergeService.merge(stockCode, results);
    }
    
    return null;
}
```

**特点**：
- 采集所有数据源
- 合并所有数据
- 按字段优先级选择最佳值
- 适合追求数据完整性的场景

## 三、数据合并服务

### 3.1 核心类

**文件位置**: `DataMergeService.java`

### 3.2 字段优先级配置

```java
// DataMergeService.java 第25-165行
@PostConstruct
public void initFieldPriority() {
    // 实时行情字段 - 优先使用FREE数据源
    fieldPriority.put("currentPrice", Arrays.asList("FREE", "TUSHARE_BASIC", "TUSHARE_PRO"));
    fieldPriority.put("changePercent", Arrays.asList("FREE", "TUSHARE_BASIC", "TUSHARE_PRO"));
    
    // 五档盘口 - 只有FREE数据源有
    fieldPriority.put("buy1Price", Arrays.asList("FREE"));
    fieldPriority.put("sell1Price", Arrays.asList("FREE"));
    
    // 估值指标 - 优先使用FREE，其次是TUSHARE_PRO
    fieldPriority.put("peRatio", Arrays.asList("FREE", "TUSHARE_PRO"));
    fieldPriority.put("pbRatio", Arrays.asList("FREE", "TUSHARE_PRO"));
    
    // 历史涨跌幅 - Tushare数据更准确
    fieldPriority.put("yesterdayChange", Arrays.asList("TUSHARE_BASIC", "TUSHARE_PRO", "FREE"));
    
    // 财务数据 - 只有TUSHARE_PRO有
    fieldPriority.put("netProfitAfterDeduction", Arrays.asList("TUSHARE_PRO"));
    
    // 行业分类
    fieldPriority.put("subIndustry", Arrays.asList("TUSHARE_BASIC", "TUSHARE_PRO", "FREE"));
}
```

### 3.3 合并流程

```java
// DataMergeService.java 第170-210行
public StockInfoDTO merge(String stockCode, Map<String, StockInfoDTO> sourceDataMap) {
    StockInfoDTO merged = new StockInfoDTO();
    merged.setStockCode(stockCode);
    
    // 1. 遍历所有字段
    for (String fieldName : getAllFieldNames()) {
        // 2. 根据优先级选择最佳值
        Object bestValue = selectBestValue(fieldName, sourceDataMap);
        // 3. 设置到合并后的对象
        setFieldValue(merged, fieldName, bestValue);
    }
    
    // 4. 计算派生字段
    calculateDerivedFields(merged);
    
    return merged;
}
```

### 3.4 选择最佳值逻辑

```java
// DataMergeService.java 第237-257行
private Object selectBestValue(String fieldName, Map<String, StockInfoDTO> sourceDataMap) {
    // 1. 获取该字段的优先级列表
    List<String> priorityList = fieldPriority.get(fieldName);
    
    // 2. 按优先级顺序查找
    for (String sourceType : priorityList) {
        StockInfoDTO data = sourceDataMap.get(sourceType);
        if (data != null) {
            Object value = getFieldValue(data, fieldName);
            if (value != null && !isEmpty(value)) {
                return value;  // 返回第一个非空值
            }
        }
    }
    
    return null;
}
```

```
假设查询股票 688606，从3个数据源获取数据：

{
  "stockCode": "688606",

  "currentPrice": 68.50,
  "changePercent": 2.35,

东方财富返回：
```

## 五、派生字段计算

### 5.1 什么是派生字段？

派生字段 = 根据已有数据计算出来的字段

### 5.2 常见的派生字段

```java
// DataMergeService.java 第308-350行
private void calculateDerivedFields(StockInfoDTO stock) {
    // 1. 开盘涨跌幅 = (开盘价 - 昨收价) / 昨收价 * 100%
    if (stock.getOpenPrice() != null && stock.getPreviousClose() != null) {
        double openChange = (stock.getOpenPrice() - stock.getPreviousClose()) 
                          / stock.getPreviousClose() * 100;
        stock.setOpenChangePercent(round(openChange, 2));
    }
    
    // 2. 涨停价 = 昨收价 * 1.10
    if (stock.getPreviousClose() != null) {
        stock.setLimitUpPrice(stock.getPreviousClose() * 1.10);
    }
    
    // 3. 跌停价 = 昨收价 * 0.90
    if (stock.getPreviousClose() != null) {
        stock.setLimitDownPrice(stock.getPreviousClose() * 0.90);
    }
    
    // 4. 统一PE字段
    if (stock.getPeRatio() == null && stock.getDynamicPE() != null) {
        stock.setPeRatio(stock.getDynamicPE());
    }
    
    // 5. 统一PB字段
    if (stock.getPbRatio() == null && stock.getStaticPB() != null) {
        stock.setPbRatio(stock.getStaticPB());
    }
}
```
