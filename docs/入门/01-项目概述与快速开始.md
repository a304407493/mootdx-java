## 一、这个项目是做什么的？

**一句话概括**：这是一个股票数据采集系统，可以从多个免费/付费数据源获取股票实时行情、财务数据等信息。

### 1.1 核心功能

```
┌─────────────────────────────────────────────────────────┐
│                    Mootdx-Java 系统                      │
├─────────────────────────────────────────────────────────┤
│  输入：股票代码 (如: 688606, 300677)                      │
│                                                         │
│  处理：从多个数据源获取数据 → 合并 → 计算派生指标          │
│                                                         │
│  输出：完整的股票信息 (价格、涨跌幅、PE/PB、市值等)         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 项目结构

```
mootdx-java/
├── javaTdx/              ← 主要业务模块 (Spring Boot)
│   ├── src/main/java/com/example/tdx/
│   │   ├── controller/   ← API接口层 (对外提供HTTP接口)
│   │   ├── service/      ← 业务逻辑层 (核心代码)
│   │   └── config/       ← 配置类
│   └── pom.xml
│
├── mootdx-server/        ← 另一个服务模块
│   └── src/main/java/com/mootdx/server/
│
└── docs/                 ← 文档目录
```

## 二、最简单的使用方式

### 2.1 启动项目

```bash
# 进入javaTdx目录
cd javaTdx

# 启动Spring Boot应用
mvn spring-boot:run
```

### 2.2 调用API获取股票数据

```bash
# 获取单只股票信息
curl "http://localhost:8080/api/stock/info?stockCodes=688606"

# 获取多只股票信息
curl "http://localhost:8080/api/stock/info?stockCodes=688606,300677"
```

### 2.3 返回数据示例

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "stockCode": "688606",
      "stockName": "奥泰生物",
      "currentPrice": 68.50,
      "changePercent": 2.35,
      "peRatio": 15.2,
      "pbRatio": 2.1,
      "totalMarket": 8200000000
    }
  ]
}
```

## 三、核心概念图解

### 3.1 数据源是什么？

数据源 = 股票数据的"供应商"

| 数据源 | 类型 | 特点 |
|--------|------|------|
| 新浪(SINA) | 免费 | 实时性好，有盘口数据 |
| 东方财富(EASTMONEY) | 免费 | 有PE/PB等估值数据 |
| 腾讯(TENCENT) | 免费 | 稳定 |
| Tushare | 付费 | 数据最全，有历史数据 |

### 3.2 系统如何工作？

```
用户请求
    ↓
Controller (接收请求)
    ↓
Service (选择数据源 → 获取数据 → 合并计算)
    ↓
返回结果
```

## 五、常见问题

### Q1: 为什么需要多个数据源？
**A**: 单个数据源可能数据不全或不稳定。多个数据源可以互补，提高数据完整性和系统可靠性。

### Q2: 免费数据源够用吗？
**A**: 对于基础行情（价格、涨跌幅）够用。如果需要历史数据、财务数据，可能需要Tushare。
