## 二、7种数据源模式详解

### 2.1 模式对比表

| 模式 | 说明 | 使用场景 | 复杂度 |
|------|------|----------|--------|
| **SINGLE** | 使用单个数据源 | 只需要基础数据 | ⭐ |
| **FREE** | 新浪+东方财富组合 | 免费获取较全数据 | ⭐⭐ |
| **FALLBACK** | 自动降级切换 | 需要高可靠性 | ⭐⭐⭐ |
| **AGGREGATED** | 多源融合-最全 | 需要最完整数据 | ⭐⭐⭐⭐ |
| **FAST** | 多源融合-最快 | 追求响应速度 | ⭐⭐⭐ |

### 2.2 模式图解

```
┌────────────────────────────────────────────────────────────┐
│  SINGLE模式 (单数据源)                                       │
│  ┌─────────┐                                                │
│  │  新浪   │ ──→ 返回数据                                   │
│  └─────────┘                                                │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  FREE模式 (免费组合)                                         │
│  ┌─────────┐   ┌─────────────┐                             │
│  │  新浪   │ ─→│  合并数据    │ ──→ 返回数据                │
│  │(价格等) │   │  (补充PE/PB) │                             │
│  └─────────┘   └──────┬──────┘                             │
│                       ↑                                     │
│                  ┌─────────┐                                │
│                  │ 东方财富 │ (补充估值数据)                 │
│                  └─────────┘                                │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  FALLBACK模式 (自动降级)                                     │
│  尝试新浪 ──→ 失败? ──→ 尝试腾讯 ──→ 失败? ──→ 尝试mootdx    │
│    ↓成功              ↓成功                ↓成功            │
│  返回数据           返回数据             返回数据            │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  AGGREGATED模式 (多源融合)                                   │
│  同时请求多个数据源 → 等待所有结果 → 按字段优先级合并          │
│  价格用新浪的，PE用东方财富的，历史数据用Tushare的...         │
└────────────────────────────────────────────────────────────┘
```

## 三、如何切换数据源模式？

### 3.1 方式一：修改配置文件

```java
// DataSourceModeConfig.java 第33-52行
private void initDefaultConfigs() {
    // 修改这里切换默认模式
    this.globalMode = "FREE";  // ← 改成你想要的模式
    
    // 可选值: SINGLE, FREE, FALLBACK, AGGREGATED, FAST, TUSHARE_BASIC, TUSHARE_PRO
}
```

### 3.2 方式二：调用API动态切换

```bash
# 切换到FREE模式
curl -X POST "http://localhost:8080/api/datasource-mode/global/mode" \
  -H "Content-Type: application/json" \
  -d '"FREE"'

# 切换到FALLBACK模式
curl -X POST "http://localhost:8080/api/datasource-mode/global/mode" \
  -H "Content-Type: application/json" \
  -d '"FALLBACK"'

# 切换到AGGREGATED模式
curl -X POST "http://localhost:8080/api/datasource-mode/global/mode" \
  -H "Content-Type: application/json" \
  -d '"AGGREGATED"'
```

### 3.3 方式三：指定单个数据源

```bash
# 只使用新浪数据源
curl -X POST "http://localhost:8080/api/datasource-mode/global/default-source" \
  -H "Content-Type: application/json" \
  -d '"SINA"'

# 只使用腾讯数据源
curl -X POST "http://localhost:8080/api/datasource-mode/global/default-source" \
  -H "Content-Type: application/json" \
  -d '"TENCENT"'
```

## 四、各模式详细配置

### 4.1 FREE模式配置

```java
// DataSourceModeConfig.java 第82-111行
public static class FreeModeConfig {
    private String primarySource = "SINA";      // 主数据源
    private String supplementSource = "EASTMONEY"; // 补充数据源
    private int batchSize = 200;                // 批量大小
    private String queryMode = "BATCH";         // 查询模式
}
```

**工作流程**：
1. 先用新浪获取基础数据（价格、涨跌幅等）
2. 再用东方财富补充PE、PB、市值等数据
3. 合并后返回

### 4.2 FALLBACK模式配置

```java
// DataSourceModeConfig.java 第113-145行
public static class FallbackModeConfig {
    private List<String> priority = Arrays.asList(
        "SINA",      // 第一优先级
        "TENCENT",   // 第二优先级
        "MOOTDX",    // 第三优先级
        "EASTMONEY"  // 第四优先级
    );
    private String queryMode = "BATCH";
    private int timeoutMs = 10000;
    private boolean failFast = false;
}
```

**工作流程**：
1. 按优先级尝试数据源
2. 任一数据源成功即返回
3. 全部失败才返回错误

### 4.3 AGGREGATED模式配置

```java
// DataSourceModeConfig.java 第147-194行
public static class AggregatedModeConfig {
    private String collectionStrategy = "SMART";  // 采集策略
    private List<String> dataSources = Arrays.asList(
        "SINA", "TENCENT", "MOOTDX", "EASTMONEY"
    );
    private String conflictResolution = "priority"; // 冲突解决方式
    
    // 字段优先级配置
    private Map<String, String> fieldPriority = new HashMap<>();
    {
        fieldPriority.put("currentPrice", "SINA");   // 价格用新浪的
        fieldPriority.put("peRatio", "EASTMONEY");   // PE用东方财富的
        fieldPriority.put("pbRatio", "EASTMONEY");   // PB用东方财富的
        fieldPriority.put("volume", "SINA");         // 成交量用新浪的
    }
}
```

**工作流程**：
1. 同时请求多个数据源
2. 等待所有结果（或超时）
3. 按字段优先级合并数据
4. 计算派生字段

## 五、配置参数说明

### 5.1 基础数据源配置参数

| 参数 | 说明 | 默认值 | 建议值 |
|------|------|--------|--------|
| batchSize | 每批查询股票数量 | 200 | 新浪200，东方财富50 |
| delayMs | 批次间延迟 | 50ms | 50-100ms |
| timeoutMs | 超时时间 | 5000ms | 5000-10000ms |
| retry | 失败重试次数 | 3 | 2-3 |
| enabled | 是否启用 | true | true |

### 5.2 查询模式说明

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| BATCH | 批量查询 | 股票数量多(>10) |
| SINGLE | 单笔查询 | 股票数量少(<=10) |
| AUTO | 自动选择 | 通用 |
