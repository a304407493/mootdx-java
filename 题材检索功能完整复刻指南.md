# 题材检索功能完整复刻指南

## 一、功能概述

题材检索功能是一个用于搜索和浏览股票题材标签的完整模块，支持从通达信mark.dat文件导入题材数据，并提供以下核心功能：

1. **题材搜索** - 根据关键词搜索题材标签
2. **热门题材展示** - 展示股票数量最多的前20个热门题材（标签云形式）
3. **题材列表浏览** - 左侧展示所有题材，支持"无题材"分类
4. **股票列表查看** - 右侧展示选中题材下的所有股票
5. **数据导入** - 支持从通达信mark.dat文件导入题材数据
6. **自定义导入路径** - 支持配置多个mark.dat文件路径

---

## 二、技术栈

- **前端**: Vue 3 + Element Plus + Vue Router + Axios
- **后端**: FastAPI + SQLAlchemy + Pydantic
- **数据库**: MySQL/SQLite（支持SQLAlchemy的数据库）

### 4.2 业务逻辑服务

```python
# backend/app/services/theme_service_v2.py
"""
通达信mark.dat题材文件解析服务 - 版本2
"""
import os
import re
import hashlib
from typing import List, Dict, Any, Optional, Tuple
from pathlib import Path
from sqlalchemy.orm import Session
from ..core.logger import setup_logging
from ..db.database import SessionLocal
from ..models.stock import StockTheme, StockThemeMapping, StockThemeDetail, StockBasic

logger = setup_logging()


class ThemeServiceV2:
    """通达信题材文件服务 - 版本2"""
    
    DEFAULT_MARK_PATH = r"C:\new_tdx\T0002\mark.dat"
    
    def __init__(self, mark_path: Optional[str] = None, file_paths: Optional[List[str]] = None):
        """
        初始化服务
        
        Args:
            mark_path: 单个mark.dat文件路径（兼容旧版本）
            file_paths: 多个mark.dat文件路径列表（新版本）
        """
        if file_paths:
            self.file_paths = file_paths
            logger.info(f"[服务初始化] ThemeServiceV2, 指定了 {len(file_paths)} 个mark文件")
        elif mark_path:
            self.file_paths = [mark_path]
            logger.info(f"[服务初始化] ThemeServiceV2, mark文件路径: {mark_path}")
        else:
            self.file_paths = [self.DEFAULT_MARK_PATH]
            logger.info(f"[服务初始化] ThemeServiceV2, 使用默认路径: {self.DEFAULT_MARK_PATH}")
    
    def _detect_encoding(self, file_path: str) -> str:
        """检测文件编码"""
        encodings = ['gbk', 'gb2312', 'utf-8', 'latin1']
        for encoding in encodings:
            try:
                with open(file_path, 'r', encoding=encoding, errors='strict') as f:
                    f.read(1024)
                return encoding
            except (UnicodeDecodeError, UnicodeError):
                continue
        return 'gbk'
    
    def _normalize_stock_code(self, code: str) -> Optional[str]:
        """标准化股票代码为 SH:600000 或 SZ:000001 格式"""
        if not code:
            return None
        
        code = code.strip()
        if len(code) > 6:
            code = code[-6:]
        elif len(code) < 6:
            code = code.zfill(6)
        
        # 判断市场
        if code.startswith('6') or code.startswith('68'):
            return f"SH:{code}"
        elif code.startswith('0') or code.startswith('3') or code.startswith('2'):
            return f"SZ:{code}"
        elif code.startswith('4') or code.startswith('8'):
            return f"BJ:{code}"
        else:
            return f"SH:{code}"
    
    def _generate_theme_id(self, theme_name: str) -> str:
        """根据题材名称生成theme_id（MD5前16位大写）"""
        hash_obj = hashlib.md5(theme_name.encode('utf-8'))
        return hash_obj.hexdigest()[:16].upper()
    
    def parse_single_file(self, file_path: str) -> Tuple[Dict[str, str], Dict[str, str], Dict[str, str]]:
        """
        解析单个mark.dat文件
        
        Returns:
            Tuple: (stock_to_theme_name, stock_to_detail, theme_name_to_color)
        """
        if not os.path.exists(file_path):
            logger.error(f"[文件错误] mark.dat文件不存在: {file_path}")
            return {}, {}, {}
        
        encoding = self._detect_encoding(file_path)
        logger.info(f"[文件解析] 开始解析: {file_path}, 编码: {encoding}")
        
        stock_to_theme_name = {}
        stock_to_detail = {}
        theme_name_to_color = {}
        
        current_section = None
        
        try:
            with open(file_path, 'r', encoding=encoding, errors='ignore') as f:
                for line_num, line in enumerate(f, 1):
                    line = line.strip()
                    if not line:
                        continue
                    
                    # 检测段落标记
                    if line.startswith('[') and line.endswith(']'):
                        current_section = line
                        continue
                    
                    # 解析键值对
                    if '=' in line:
                        parts = line.split('=', 1)
                        if len(parts) != 2:
                            continue
                        
                        key = parts[0].strip()
                        value = parts[1].strip()
                        
                        # 标准化股票代码
                        stock_code = self._normalize_stock_code(key)
                        if not stock_code:
                            continue
                        
                        if current_section == '[TIPWORD]':
                            stock_to_theme_name[stock_code] = value
                        elif current_section == '[TIP]':
                            stock_to_detail[stock_code] = value
                        elif current_section == '[TIPCOLOR]':
                            theme_name_to_color[value] = key
            
            logger.info(f"[解析完成] {file_path}: 映射 {len(stock_to_theme_name)}条, "
                       f"描述 {len(stock_to_detail)}条, 颜色 {len(theme_name_to_color)}条")
            
        except Exception as e:
            logger.error(f"[解析错误] 解析 {file_path} 失败: {e}")
        
        return stock_to_theme_name, stock_to_detail, theme_name_to_color
    
    def parse_mark_file(self) -> Tuple[Dict[str, str], Dict[str, str], Dict[str, str]]:
        """解析所有mark.dat文件（支持多个文件，后覆盖前）"""
        merged_stock_to_theme_name = {}
        merged_stock_to_detail = {}
        merged_theme_name_to_color = {}
        
        for file_path in self.file_paths:
            stock_to_theme_name, stock_to_detail, theme_name_to_color = self.parse_single_file(file_path)
            
            merged_stock_to_theme_name.update(stock_to_theme_name)
            merged_stock_to_detail.update(stock_to_detail)
            merged_theme_name_to_color.update(theme_name_to_color)
        
        logger.info(f"[合并完成] 共解析 {len(self.file_paths)} 个文件")
        
        return merged_stock_to_theme_name, merged_stock_to_detail, merged_theme_name_to_color
    
    def import_themes_to_db(self, db: Session = None) -> Dict[str, Any]:
        """导入题材数据到数据库"""
        logger.info("[导入开始] 开始导入题材数据到数据库")
        
        stock_to_theme_name, stock_to_detail, theme_name_to_color = self.parse_mark_file()
        
        if not stock_to_theme_name:
            logger.warning("[导入警告] 未解析到任何题材数据")
            return {"success": False, "message": "未解析到数据"}
        
        should_close_db = db is None
        if db is None:
            db = SessionLocal()
        
        try:
            result = {
                "themes_added": 0,
                "themes_updated": 0,
                "mappings_added": 0,
                "details_added": 0,
                "details_updated": 0
            }
            
            # 1. 创建theme定义
            logger.info("[导入步骤] 1. 创建题材定义")
            unique_themes = set(stock_to_theme_name.values())
            logger.info(f"[题材定义] 发现 {len(unique_themes)} 个唯一题材")
            
            theme_name_to_id = {}
            
            for theme_name in unique_themes:
                theme_id = self._generate_theme_id(theme_name)
                theme_name_to_id[theme_name] = theme_id
                
                existing = db.query(StockTheme).filter(
                    StockTheme.theme_id == theme_id
                ).first()
                
                color = theme_name_to_color.get(theme_name, "")
                
                if existing:
                    existing.theme_name = theme_name
                    existing.color = color
                    result["themes_updated"] += 1
                else:
                    theme = StockTheme(
                        theme_id=theme_id,
                        theme_name=theme_name,
                        color=color
                    )
                    db.add(theme)
                    result["themes_added"] += 1
            
            db.flush()
            
            # 2. 导入股票-题材关联（先清空）
            logger.info("[导入步骤] 2. 导入股票-题材关联")
            db.query(StockThemeMapping).delete()
            
            for stock_code, theme_name in stock_to_theme_name.items():
                if ':' in stock_code:
                    market, code = stock_code.split(':', 1)
                else:
                    market = 'SH' if stock_code.startswith('6') else 'SZ'
                    code = stock_code
                
                theme_id = theme_name_to_id.get(theme_name)
                if not theme_id:
                    continue
                
                mapping = StockThemeMapping(
                    code=code,
                    market=market,
                    theme_id=theme_id
                )
                db.add(mapping)
                result["mappings_added"] += 1
            
            # 3. 导入详细描述
            logger.info("[导入步骤] 3. 导入题材详细描述")
            for stock_code, detail_text in stock_to_detail.items():
                if ':' in stock_code:
                    market, code = stock_code.split(':', 1)
                else:
                    market = 'SH' if stock_code.startswith('6') else 'SZ'
                    code = stock_code
                
                existing = db.query(StockThemeDetail).filter(
                    StockThemeDetail.code == code,
                    StockThemeDetail.market == market
                ).first()
                
                if existing:
                    existing.detail_text = detail_text
                    result["details_updated"] += 1
                else:
                    detail = StockThemeDetail(
                        code=code,
                        market=market,
                        detail_text=detail_text
                    )
                    db.add(detail)
                    result["details_added"] += 1
            
            # 4. 更新统计
            logger.info("[导入步骤] 4. 更新题材统计")
            self._update_theme_stats(db)
            
            db.commit()
            logger.info(f"[导入完成] 结果: {result}")
            return {"success": True, **result}
            
        except Exception as e:
            db.rollback()
            logger.error(f"[导入错误] 导入题材数据失败: {e}")
            import traceback
            traceback.print_exc()
            return {"success": False, "message": str(e)}
            
        finally:
            if should_close_db:
                db.close()
    
    def _update_theme_stats(self, db: Session):
        """更新题材股票数量统计"""
        from sqlalchemy import func
        
        stats = db.query(
            StockThemeMapping.theme_id,
            func.count(StockThemeMapping.id).label('count')
        ).group_by(StockThemeMapping.theme_id).all()
        
        for theme_id, count in stats:
            theme = db.query(StockTheme).filter(
                StockTheme.theme_id == theme_id
            ).first()
            if theme:
                theme.stock_count = count
        
        db.flush()
        logger.info(f"[统计更新] 更新了 {len(stats)} 个题材的统计信息")
    
    def search_themes(self, keyword: str, db: Session) -> List[Dict[str, Any]]:
        """根据关键词搜索题材"""
        from sqlalchemy import or_
        
        themes = db.query(StockTheme).filter(
            or_(
                StockTheme.theme_name.contains(keyword),
                StockTheme.theme_keywords.contains(keyword)
            )
        ).all()
        
        return [{
            "theme_id": t.theme_id,
            "theme_name": t.theme_name,
            "theme_keywords": t.theme_keywords,
            "description": t.description,
            "color": t.color,
            "stock_count": t.stock_count
        } for t in themes]
    
    def get_theme_stocks(self, theme_id: str, db: Session) -> Dict[str, Any]:
        """获取题材关联的股票列表，包含股票详细介绍"""
        theme = db.query(StockTheme).filter(
            StockTheme.theme_id == theme_id
        ).first()
        
        if not theme:

        mappings = db.query(StockThemeMapping).filter(
            StockThemeMapping.theme_id == theme_id
        ).all()
        
        stocks = []
        for mapping in mappings:
            stock_basic = db.query(StockBasic).filter(

            stock_info = {
                "code": mapping.code,

                "name": stock_basic.name if stock_basic else "",
                "industry": stock_basic.industry if stock_basic else "",
                "detail": stock_detail.detail_text if stock_detail else ""
            }
            stocks.append(stock_info)
        
        return {
            "theme_id": theme_id,
            "theme_name": theme.theme_name,
            "stock_count": len(stocks),
            "stocks": stocks
        }
    
    def get_all_themes(self, db: Session) -> List[Dict[str, Any]]:
        """获取所有题材列表"""
        themes = db.query(StockTheme).all()
        
        return [{
            "theme_id": t.theme_id,

            "description": t.description,

        } for t in themes]
    
    def get_stock_themes_by_stock(self, code: str, market: str, db: Session) -> Dict[str, Any]:
        """获取指定股票的题材信息"""
        stock_basic = db.query(StockBasic).filter(

            if theme:
                themes.append({

                    "theme_name": theme.theme_name,

                    "color": theme.color,

            "code": code,

            "themes": themes,
            "detail": detail.detail_text if detail else None
        }
    
    def get_stocks_without_theme(self, db: Session) -> Dict[str, Any]:

        return {

            "stocks": stocks
```

```vue
  const sortedThemes = [...allThemes.value].sort((a, b) => b.stock_count - a.stock_count)
  // 在开头添加"无题材"选项
  sortedThemes.unshift({
    theme_id: 'NO_THEME',
    theme_name: '无题材',
    theme_keywords: '未分类',
    description: '没有任何题材关联的股票',
    color: null,
    stock_count: noThemeCount.value
  })
  return sortedThemes
})

  return allThemes.value
```

## 七、交互细节说明

### 7.1 页面加载流程

1. 页面初始化时调用 `fetchThemeList()` 加载所有题材
2. 同时调用 `fetchNoThemeCount()` 获取无题材股票数量
3. 渲染热门题材标签云（取stock_count最多的前20个）
4. 渲染左侧题材列表（按stock_count降序排列，顶部插入"无题材"选项）

### 7.2 搜索交互流程

1. 用户在搜索框输入关键词，按Enter或点击搜索按钮
2. 调用 `handleSearch()` 方法
3. 显示loading状态
4. 调用API `/themes/search?keyword=xxx`
5. 结果存入 `searchResults`
6. `filteredThemes` 计算属性自动更新显示搜索结果
7. 无结果时显示提示"未找到匹配的题材"

### 7.3 题材选择交互流程

1. 用户点击左侧题材列表中的某一项
2. 触发 `selectTheme(theme)` 方法
3. 设置 `selectedTheme` 为当前选中题材
4. 显示loading状态
5. 判断是否为"无题材"（theme_id === 'NO_THEME'）
   - 是：调用 `getNoThemeStocks()` API
   - 否：调用 `getThemeStocks(theme_id)` API
6. 结果存入 `themeStocks`
7. 右侧股票列表自动渲染
8. 每个股票卡片显示：名称、市场标签、代码标签、行业标签、操作按钮、详细介绍

### 7.4 数据导入交互流程

1. 用户点击"导入设置"按钮
2. 调用 `showImportDialog()`
3. 调用API `/themes/import-path` 获取默认路径信息
4. 显示对话框，展示：
   - 默认导入路径（只读）
   - 文件存在状态标签
   - 自定义路径列表（可添加/删除）
5. 用户可添加多个自定义路径
6. 点击"保存设置"关闭对话框
7. 用户点击"导入题材数据"按钮
8. 调用 `handleImport()`
9. 判断是否有自定义路径
   - 有：调用 `importThemesWithPaths(validPaths)`
   - 无：调用 `importThemes()`
10. 显示导入结果消息
11. 刷新题材列表

### 7.5 标签颜色规则

| 股票数量 | 标签类型 | 颜色 |
|---------|---------|------|
| >= 50 | danger | 红色 |
| >= 20 | warning | 橙色 |
| >= 10 | success | 绿色 |
| < 10 | info | 灰色 |

## 十、注意事项

1. **编码问题**：mark.dat文件默认使用GBK编码，解析时需要自动检测编码
2. **股票代码标准化**：统一转换为 `SH:600000` 或 `SZ:000001` 格式
3. **市场判断规则**：
   - 6开头或68开头 → SH（上海）
   - 0开头、3开头或2开头 → SZ（深圳）
   - 4开头或8开头 → BJ（北京）
4. **theme_id生成**：使用MD5(theme_name)的前16位大写
5. **导入策略**：
   - 每次导入先清空stock_theme_mapping表
   - 同名题材更新，新题材插入
   - 详细描述更新或插入
6. **并发安全**：数据库操作使用事务，失败时回滚
7. **跨域配置**：开发环境允许所有来源，生产环境需要限制
